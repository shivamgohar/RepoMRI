# RepoMRI - GitHub Repo Full Body Scanner 🧬

> The health report GitHub never gave you.

A novel tool that analyzes any GitHub repo for hidden risks that GitHub Insights doesn't show.

### What it does (that GitHub doesn't):
- **Bus Factor Score**: Kitne logo ke jaane se project marega?
- **Zombie Code Detector**: Dead code jo abhi bhi build me hai
- **Dependency Rot & CVE Scanner**
- **Secret Leak History**
- **PR Bottleneck Analysis**
- **Code Knowledge Map**

### Live Demo
Hosted on GitHub Pages: `https://YOUR_USERNAME.github.io/RepoMRI/`

### Tech Stack
React + Tailwind + Recharts - Pure frontend, no backend needed.

### How to Use
1. Paste any GitHub URL
2. Click Scan
3. Get full health report + Fix-It AI checklist
